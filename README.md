# Дашборд учебного отдела

Мониторинг план-факта обучения. Сервер на Node.js (Express), интерфейс в папке `public/`.

## Запуск

```bash
npm install
cp .env.example .env   # заполните значения
npm start
```

Приложение откроется на http://localhost:3000.

## Данные

В репозитории нет рабочих данных. Файл `data.json` создаётся автоматически при первом запуске с начальным состоянием. Выгрузки статусов, презентации и обратная связь лежат в папках `Статусы/`, `Отчет презентация неделя/`, `feedback/`. Они исключены из git через `.gitignore`.

Подробное описание проекта: [PROJECT_HANDOVER.md](PROJECT_HANDOVER.md).
