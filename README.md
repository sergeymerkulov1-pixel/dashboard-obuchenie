# Дашборд учебного отдела

Мониторинг план-факта обучения. Сервер на Node.js (Express), интерфейс в папке `public/`.

## Запуск

```bash
npm install
cp .env.example .env   # заполните значения
npm start
```

Приложение откроется на http://localhost:3000.

## Данные

Репозиторий приватный: в нём лежит рабочий `data.json` (история срезов, план-график, журнал, пользователи). Не делайте репозиторий публичным. Выгрузки статусов, презентации и обратная связь лежат в папках `Статусы/`, `Отчет презентация неделя/`, `feedback/` и исключены из git через `.gitignore`.

Подробное описание проекта: [PROJECT_HANDOVER.md](PROJECT_HANDOVER.md).
